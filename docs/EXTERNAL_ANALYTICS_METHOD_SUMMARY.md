# Resumo metodológico

A única integração desta entrega que altera a aritmética do SARI é Common Crawl, exclusivamente via `BR-GEO-060` positive-only.

```text
DISCOVERY_ACCESS = 15% do SARI
EXTERNAL_CRAWL_CORROBORATION = 3% de DISCOVERY_ACCESS
impacto máximo teórico = 0,45 ponto Overall
```

Sem BR-GEO-060, as proporções técnicas anteriores são preservadas exatamente por normalização. CrUX History e Clarity permanecem fora do SARI.
